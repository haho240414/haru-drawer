# 상세 요약 기준

앱과 파일 보고서의 본문은 원문이 충분하면 영상·링크별 6~10문장과 2~3단락으로 정리한다. 핵심 주장, 주장에 대한 이유와 작동 방식, 수치·단위·사례, 참고할 점과 미확인 부분을 설명한다. 핵심 포인트는 4~7개를 목표로 하되 단어 나열 대신 조건과 근거를 담은 문장으로 쓴다.

원문이 부족하면 목표 분량을 억지로 채우지 않는다. 자막 일부만 확보했으면 그 범위를 밝히며, 자막이 없으면 제목·설명 기준임을 유지한다. 경제 영상의 주장과 전망은 제작자의 설명으로 표현한다. 설명의 광고·모집·구매 링크를 영상의 핵심으로 대신하지 않는다. 휴식 영상에는 숙제를 만들지 않는다.

일일 보고서의 종합 요약과 주제별 흐름도 여러 문장으로 설명한다. 잠금 카드의 3줄 제한과 폰 bundle의 기존 형식은 유지한다. 앱의 본문은 빈 줄로 나뉜 단락을 표시하고, 저장용 Markdown의 주 보고서에서도 항목별 상세 본문·핵심 포인트를 바로 읽을 수 있다.

입력 분량은 유튜브 설명 최대 4,000자, 확보 자막 최대 16,000자, AI에 전달하는 본문 최대 12,000자다. 이는 전체 영상 분석을 보장하는 길이가 아니며 부분 자료 표시를 유지한다. AI 분석에 summary_version=2를 기록해 이전의 짧은 분석을 새 상세 분석 대신 재사용하지 않는다. 같은 버전의 상세 분석은 다시 공유된 링크에서 재사용한다.

검증: 기존 47개에 상세 분석 캐시의 교체·재사용, 주 Markdown/HTML에 전체 문단과 포인트 보존, 이전 2,500자 제한 뒤의 근거 전달 검증 3개를 추가했다. 전체 50개가 통과했다. 렌더링은 CUA로 데스크톱과 모바일에서 문단·근거 펼치기·콘솔·가로 넘침을 확인했다.
